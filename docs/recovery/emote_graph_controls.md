# Emote graph, mouth and blink controls

Reference: original `sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Read-only Binary Ninja view `candidate:view:1:UEU`; addresses below are executable VAs.

- `0x1402f6b20` owns/normalizes integer edges, merges multiple same-group points inside each edge, then splits edges at remaining interior points. The merge sum wraps 32 bits; assembly sign-extends it to RAX and uses unsigned `div r8`. Endpoint groups form an ordered bidirectional weighted graph.
- `0x1402f76f0` uses the first lowest-distance unvisited node and strict distance improvement. Route reconstruction selects the first matching adjacency edge, reverses node/cost arrays, and retains the original reverse-accumulation cost sum.
- `0x1402f7e40` tries lower/lower, upper/lower, lower/upper, upper/upper in that order and retains the first strict minimum. Same-edge kind1 interpolates directly; absent/disconnected kind0 returns target for every positive fraction. `0x1402f8610` traverses source leg, graph edges and destination leg. Tests distinguish zero-distance equivalent endpoints and candidate ties.
- Eyebrow metadata `0x1402c3b50` uses `edge` and singular `node`; `0x1402d5590` initializes the current frame from `beginFrame`. Setter/update `0x1402d56d0/0x1402d5630` use the actual graph plus native easing.
- Mouth `0x1402c57a0/0x1402d6560` initializes integer frame and zero talk. `0x1402d6a60` ignores duration/easing and truncates the frame. Default nonqueued talk setter `0x1402d6a70` replaces pending transitions except an already active identical target with a longer requested duration. `0x1402d6860` starts pending work during the same update, increments normalized progress, and completes at `progress-1 >= floatBits(0xb8d1b717)`. Explicit enqueue mode remains outside this component.
- Eye setup `0x1402c2b30` obtains one `rand_s` word via `0x14056df40` and seeds a distinct 64-bit PCG. `0x1402d5940` consumes one output per eye for the initial interval. `0x1402d5cb0` advances at most one interval/blink transition per call; overshoot is discarded. Suppression prevents new blinks without cancelling an active one. `0x1402d5b40/0x1402d5be0/0x1402d5c30` modulate a frame only for a nonzero parameter-index word and an inclusive forward or reversed range.

The portable blink primitive takes an explicit entropy word and actual timing/range/index inputs. The containing variable publisher now owns three graph channels and a blink per eye, with one actual entropy-word callback feeding a shared PCG. Assembly confirms `0x1402c2c66` stores original `beginFrame` at definition `+4`, while `+0` may become zero for Velvety. `0x1402c3671..0x1402c3696` computes and stores the actual blink-parameter lookup index at `+0x58` (or -1 when absent). The decompiler hides these temporary stores, and its block listing is not address-ordered. `0x1402d5940` copies the original range and lookup index. It does not read metadata `blinkEnabled`. All three current channels copy effective beginFrame. An omitted entropy service gates publication; other required families retain their explicit gates. Blink parameter selection rejects out-of-range indices before accessing native-unsafe offsets.

Candidate tests are source-authored executable-derived checks, not new native differential captures. No compiler, native probe or app execution was performed while authoring this candidate.
