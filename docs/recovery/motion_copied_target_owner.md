# Motion copied-target ownership

`MotionCopiedTargetOwner` implements the real offscreen owner behind the separate [copied-target size policy](motion_copy_target.md). The reference is `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. This owner is separate from motion source textures and the immutable resource cache.

Native `0x1404c6ac0` deletes the previous 72-byte wrapper before storing replacement dimensions and creating its successor. The wrapper is type 1, has one mip, takes the current target's original format only on replacement, and has no swapchain or depth owner. `0x1404c34a0` creates a real kind-5 `MTexture` through `0x1404f8410`: default GPU usage, one mip/sample, shader-resource plus render-target binds. `0x1404c3930` then creates a separate render-target view using a null D3D view descriptor.

A failed render-target-view request releases the `MTexture` shader view and texture, frees that owner and clears the wrapper's texture pointer. The outer wrapper is still installed. A later request within the existing inclusive half-to-full size interval retains that failed target; it does not silently retry creation. `Texture()` therefore returns null for this measured state. A genuine resize can replace it normally.

The deleting destructor `0x1404c2710` releases the `MTexture` through `0x1404f8520`, frees it, and then releases the separately retained render-target view. The portable owner preserves texture-before-render-view retirement, including replacement and nonthrowing idempotent `Close()`. The platform render view must own the required physical resource lifetime independently. `MutableTextureOwner::Resource()` is a narrow borrow of its actual abstract resource; it exposes no platform handles and extends no lifetime.
