# Screen texture projection

Original `sgre_steam.exe` SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8` registers `ScreenProjection` at `0x140245920` as a `SQLayerBase` descendant. Its constructor `0x140244f10` creates the actual common Layer graph, retains the supplied Screen, constructs `MVirtualScreenView` at `0x1404fa080`, clears its hidden byte and attaches it beneath the common camera. `0x140244c80` releases the strong Screen before deleting the common Layer graph.

`0x1404fa480` samples the original Screen target. Its source normalized coordinates scale by logical Screen dimensions divided by actual allocated texture dimensions; the destination uses the fixed view bounds. Each region writes native format8 XYZ/UV vertices in bottom-right, bottom-left, top-right, top-left order and indices `0,1,2,1,3,2`. Depth remains the genuine third position component. The default view has one full normalized region, white uniform color and enabled native blend0. `0x140245d90` applies common Layer smoothing before setting the view filters. The `getWidth` and `getHeight` methods report logical view extent.

VS10 is occurrence632 at file offset `0x737580`, SHA-256 `3ec17e4a717f17df7f6401dfbe160c1b531833a3af35daaa52ca41892dba66f2`. It computes four `dp4` position components from XYZ/1 and cb0 registers0–3, takes uniform color from register4 and forwards UV. The readable HLSL and Metal translation preserve those inputs. No cross-API bit identity or native pixel capture is claimed by source recovery.

The runtime borrows the target texture from its actual same-domain render owner; no pixels are copied into an Image. The source Screen's script owner encloses the projection. Queued command buffers retain their actual GPU resources, and source-handle generations retire with the target. Sampling an active color attachment is rejected rather than assigning replacement contents. Source/filter/clip/camera state and six-index triangle submission use the containing graphics frame and physical-frame host pool.

The admitted packet count is bounded to the native16-bit writer domain before the shared allocator changes index width. Nonfinite geometry, insufficient scratch, foreign/stale textures, mismatched input formats and release through the wrong owner reject. The ordinary projection and the separately registered chromatic projection below use these actual sampled-target owners. Additional view-editing operations remain open.

`NativeTextureRef` is a separate native Object registered at `0x14029d610`. Its constructor `0x14029d130` accepts Screen, RawTex or Image and retains the actual source. For Screen, `0x14053a6c0` stores the physical texture extent and the distinct active rectangle `{0,0,logicalWidth,logicalHeight}`. The original Motion registration `0x140278770` retains that object by layer name and `0x14052b150` installs an actual `AlternateTextureLayerListener`. Listener source/material substitution remains a separate recovery requirement; projecting a Screen does not complete phone alternate-texture rendering.

`ScreenProjectionCA` registers at `0x140062040` as a direct `SQLayerBase` sibling. Constructor `0x140061520` retains the Screen and appends three actual views, with native RGBA colors red/green/blue and blend modes 0/1/1. `0x1404fa480` converts view RGBA to record ARGB. The first pass supplies source alpha; the two additive passes preserve destination alpha through the recovered blend table. CA inherits common Layer smoothing without the ordinary projection’s view-filter override.

The `setRMesh`, `setGMesh` and `setBMesh` methods (`0x140062680`, `0x140062650`, `0x140062620`) invoke `0x140061800`. It replaces that channel’s initial whole-view region with four source quadrants. Destination corners combine pixel displacement divided by actual view dimensions with a zoom margin computed in double and narrowed before float interpolation. Wrapper `0x140061290` initializes missing or nonnumeric mesh arguments to zero. Sixty-four bounded original-instruction executions match all 2,048 output float words exactly; dimension queries, heap allocation/free and the observed region submission are explicit foreign boundaries. This establishes the mesh calculation, not a complete native renderer replay.

The hidden Metal fixture validates both sibling classes, real Screen rendering, default and four-region RGB composition, independent red/blue displacement, inherited CA filter behavior, hidden Layers, aborted-frame retry and active-attachment rejection. It requests no OS drawable or visible window. Native pixel comparison, effect timing and complete game composition remain open.
