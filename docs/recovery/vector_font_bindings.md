# VectorFont script resource lifetime

Target: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. All addresses are executable virtual addresses. No executable bytes or analysis metadata were changed.

Registration at `0x140088c10` creates `VectorFont` directly below `Object`. This class is distinct from abstract `Font`, `PSBFont` and `SystemFont`. Its actual methods are `constructor`, `weakref`, `getLoading`, `getSize` and `setSize`; there is no `ready` method. The registered weak-reference function `0x140039f50` uses the last stack value and passes primitive values through.

The constructor factory `0x140088970` accepts the receiver and resource name, then optional integer shaping mode and language string, with later arguments ignored. Missing mode is 0; missing language is `en`. The original numeric conversion at `0x140222ff0` accepts integer/float/bool and falls back to zero on failed conversion. Name and language use exact string extraction at `0x140223470`, then C-string length/copy; embedded NUL terminates the owned string. Failed string extraction becomes a null pointer followed by `strlen`, so the portable adapter rejects non-string fields with an explicit safety error. Name and instance storage have checked limits before allocation.

Construction initializes native Object ownership and immediately acquires a resource reference through `0x140248dc0` with binary kind 1 and the wrapped-source filter enabled. This requests the original name plus `.m`, preserving its spelling. `ScriptResourceBindings::TypedAssetRequest` supplies the same `BinaryWrapped` preparation service; it schedules owned host work and returns a readiness observer. Construction does not poll, decode a font or create textures.

`getLoading` at `0x140088bc0` inverts resource completion from `0x140248cd0`. Completed resources are promoted into active ownership independently of data kind or success; even a completed failure or PSB resource ends loading. The adapter reports a bounded failure diagnostic once, retaining completed status before entering a fallible/reentrant error consumer. Polling observes already prepared data and performs no file I/O or font parsing.

Lazy loading at `0x140088b10` queries only a promoted resource. It accepts raw binary kind 1, builds a private vector core using bytes/length/mode/language, and reuses it thereafter. The portable `Provider` and actual `getSize`/`setSize` methods perform the recovered lazy preparation after completion. Call this during resource/font preparation, before ordinary drawing. Optional `ActiveAssetFind` queries the globally active manager map without promoting pending work or acquiring another reference. This preserves a resource that another owner already promoted, even before this wrapper calls `getLoading`; the adapter keeps its original request lease until retirement while borrowing the query result. Without that service, an own completed observation is required before provider use. The optional `TryProvider` follows native `0x140088950` for FontInfo construction: pending, failed or wrong-kind data returns a null provider while retaining the resource owner. It performs no readiness polling. Malformed raw font bytes still raise a decoding error. Required `Provider` and script getter/setter use explicitly reject unavailable data; the native getter/setter can dereference a null core in those cases. The real first-party SFNT/default-CFF provider and its remaining shaping/TrueType limitations are described in [vector_font.md](vector_font.md).

The native destructor `0x140088830` deletes the private core before releasing the resource reference at `0x140249c60`, then destroys language/name strings before Object completion. The adapter follows that order for explicit deletion, automatic VM reclamation, VM Close and failed completion notifications. VM/Object adapters must outlive this binding and its callbacks. `Provider` returns a borrowed reference: native `FontInfo` at `0x140039860` retains the supplied VectorFont wrapper itself, so [ScriptTextFontInfo](text_font_info.md) retains that wrapper for the whole provider borrow and destroys its private interface first. Indicator's generic Font path has a different underlying-PSB-root lifetime and cannot substitute for this relationship.
