Division selection `0x14051bb30` adds player offset+0x164 to selected source-manager angle+0x20, repeatedly normalizes float32 by 360 degrees, and finds the first interval `(division[i-1], division[i]]`, starting at index1. If none matches, modulo count selects index0. It preserves serialized boundary order, including unsorted or equal boundaries. The child lookup occurs only when the selected index changes. `EvaluateMotionDivisionIndex` implements the index calculation and does not start playback. Its finite angle/entry limits prevent native hangs and invalid modulo; no performance equivalence is claimed.

Actual variable/layer preparation and event traversal remain external unrecovered phases, so this is not a complete player or a Motion script class.
