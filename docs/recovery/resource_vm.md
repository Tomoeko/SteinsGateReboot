`PsbResourceJobs` executes bounded caller-owned archive readers and PSB parsing on one owned worker. The owner thread publishes completed buffers/documents into the actual cache between frames. Publication does no filesystem access or decoding and does not wait for worker completion. Its input queue is bounded and preallocated; one result can wait for publication while one further result is decoded. Stop/join is explicit, pending handles receive shutdown diagnostics, and decoded metadata is reclaimed after cache-generation eviction. This establishes an authored host boundary, not exact native worker concurrency, wakeup, cancellation, or prioritization parity. Readers must enforce their source allocation limits before producing a buffer. The queue passes independent ASan/UBSan and ThreadSanitizer fixtures for owner/worker separation, publication, bounds, failures, retention, and shutdown. A streamed optional local check decodes all 20 original PSB configuration entries on the worker, excluding the separate raw license entry.

PSB charge is the complete supplied file length. Constructor `0x1404c9130` stores its size argument at object offset `+0x28`; charge getter `0x1404d04a0` returns that word. Initializer `0x1404cd530` separately computes stream-entity size as the file length minus chunk-data offset and stores it at `+0xa0`; this smaller value is not the manager charge.

## Opt-in VM reclamation ownership

Binary, Resource and PSBObject native registries borrow complete VM object identities (owner, arena index and generation), rather than storing strong script-instance values. Their class metadata has explicit native host roots. Each Object-derived instance configures the singular Object release bridge: script destructor first, derived native buffers/targets/document records next, then Object completion observers/base roots. Resource unload `0x14024c630` releases manager references in forward target order before destroying target names; the authored unload/finalizer/destruction paths explicitly release prepared/pending payloads in that order. Derived records are removed before base notification, so a script or subscriber diagnostic cannot leave an occupied native registry slot. Expired adapter callbacks use weak owners and report their existing expiry diagnostic.

PSBValue is a plain native class with its own VM release hook. Its document owner is an explicit `SquirrelHostRoot`; keeping a C++ decoded document alive does not alone mark the script PSBObject during collection. Releasing a proxy erases that record and its document root. Document identity is resolved only when conversion needs the actual owner value. Integrated ASan/UBSan true-reclaimer fixtures pass for immediate binary release, generation reuse, pending Resource jobs and diagnostic ordering, independent cache pins, and child proxies marking their owner across collection. Common VM reclamation remains opt-in; broader native finalization/worker-cancellation parity remains open.
