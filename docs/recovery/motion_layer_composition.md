## Direct native evidence

Layer creation `0x14050dca0` clears each `0x418`-byte selected node, initializes evaluated visibility/active flags, sets enabled/visible overrides true, zoom overrides one and opacity override 255, stores parent as a relative index, then recurses children in serialized order. The full composition function is `0x14050c550`, using actual local evaluation `0x14050bc40`, transforms `0x14050ed50`, variable phase `0x14050e530` and geometry phase `0x140520d80`.

- Immediate parent is relative index `node+0x38`. While the ancestor's inheritance mask `+0x3c` contains `0x400000`, composition follows that ancestor's own parent. Selected ancestor supplies coordinates, visibility, transforms and inherited modulation. Root terminates the bounded parent chain.
- Current frame hidden is `node + activeSlot*0x120 + 0x120`. It is distinct from evaluated visible `+0x356` and evaluated active `+0x355`.
- For a present frame, evaluated visible is override-visible `+0x382` AND selected-parent visible. Active additionally requires override-enabled `+0x381`; inherited/composed modulation alpha zero then suppresses active without changing visible.
- For an absent frame, the selected parent's evaluated pose and matrix are copied. Visible remains parent-visible AND override-visible; active is false. Numeric child overrides are ignored. An absent parent frame can therefore pass visibility and a pose to an active child.
- Present poses XOR flips with `+0x383/+0x384`, add angle `+0x394`, multiply zoom by `+0x398/+0x39c`, add shear `+0x3a0/+0x3a4`, apply unsigned byte opacity product divided by 255 with `+0x3a8`, and add coordinates `+0x388/+0x38c/+0x390` before parent mapping and recovered inheritance arithmetic.
- Modulation mask `0x200` selects parent modulation. A present frame's color modifier composes afterward; absent frames retain only the inherited/default value. Inherited arithmetic delegates to the existing independently recovered `ComposeMotionHierarchyLayer` after these native orchestration choices, rather than deriving those choices from that scalar helper.
- Composition saves each previous evaluated position before traversal. Assigned tick `player+0x191` makes displacement `+0x94/+0x98/+0x9c` zero; otherwise displacement is new minus previous evaluated coordinates. Native assigned/dirty flags clear only at the tail, after this phase.
