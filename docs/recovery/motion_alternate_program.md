# Alternate motion program selection

Target `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Addresses are unchanged virtual addresses in the explicitly selected PE view.

`0x140532140` dispatches ordinary phases 0, 1 and 6 to `0x14054d8a0` when blend-family flags are 0x100. The alternate family uses the same twelve vertex layouts, matrix resolution and vertex-color preparation as the ordinary family. Its texture/color/auxiliary groups are also the same, while color-filter selection is absent. Pixel programs start at 900 and each group contains 19 operations.

Operation `(blend & 0xff0f)` 0x100..0x10c selects offsets 1..13. Mode 0x10d truncates its finite positive-domain parameter to an integer, takes modulo 5 and reads offsets 14..18 from `0x140654a98`. Native unknown-operation dispatch selects offset 0. Pixel index is `900 + (texture*12+color+auxiliary)*19+operation`. Pipeline byte +0x459 forces pixel index 900. Reflected pixel metadata indexes the relative value `pixelIndex-900`, unlike the ordinary family's absolute pixel index. Selection alone does not establish translated pixel semantics for these programs.

The entry calls `0x1404c4bd0` before selection. That function computes and copies a target region, publishes a copied texture at pipeline +0x450 and UV scale/offset at graphics +0x150..0x15c. This is a GPU/owner boundary, not a pure selector. The CPU module requires a caller-prepared copied target and does not recreate/copy/bind it. `0x1404c2a60` returns the four UV affine values directly; available metadata at relative index*16+0x4800 receives them.

Available metadata at relative index*16+0x8f40 receives mode-specific values. For 0x10c, `0x14054dcc5..0x14054dd94` forms centered target extents, divides their maximum by the amount and applies original float ceiling at `0x1405810c0`. With quantized size `q`, signed copied dimensions `w,h`, it produces `[w/q,h/q,(q*0.5+0.5)/w,(q*0.5+0.5)/h]`. For 0x10d, `0x14054ddcd..0x14054de46` truncates the parameter and chooses `[1/w,0,0,0]` below 5 or `[0,1/h,0,0]` at/above 5. Prepared source dimensions are signed integer conversions, distinct from unsigned current-target conversions.
