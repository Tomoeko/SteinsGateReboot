# TrueType prepared point execution

The point owner adds MDAP, IUP, SHC[1], SHPIX, ALIGNRP, MIAP, GC, SCFS and MD to the existing bounded stack/control/state interpreter. Existing entry points retain their point-operation gates. The new entry point receives distinct owned twilight and glyph arrays; zone selectors alias these owners. Original, current and unscaled coordinates, tags, contours and phantom points remain separate.

The reference executable SHA-256 is `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Point dispatch is at `0x1403B6C6B..0x1403B7396`; contour shift is `0x1403B35C0`, pixel shift `0x1403B3A60`, IUP `0x1403B2AF0`, interpolation `0x1403B90D0`, and original distance `0x1403B2D70`. The original prepared-context witness completed 110 cases and 111 calls with 44,850 native instructions. The portable whole-state comparison matches all 110 cases and 111 calls. All 44 connected sanitizer groups pass; an independent audit verifies 1,165 executed sites and 4,897 PE bytes.

Native behavior retained includes low16 reference indices versus full32 GC indices, MIAP reference publication on invalid input, twilight original/current transfers, physical reference exclusion, variable-loop error state, version-40 movement suppression, per-call IUP flags, and interpolation across three coordinate spaces. Single-touch IUP adds displacement to existing current coordinates. Integer operations retain low32 wrapping and original fixed-point rounding.

The current geometry domain requires positive unit-axis projection, dual-projection and freedom vectors. Each zone is bounded to 32,767 points with complete arrays and ordered in-range contours. Point visits are capped at four million per call as an authored input-work limit. Non-axis geometry, SHC[0], other unimplemented opcodes, glyph-loader initialization, full font preparation and hinted raster admission remain explicit recovery boundaries. This module does not enable TrueType rendering by itself.
