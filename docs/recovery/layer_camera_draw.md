# Genuine 3×4 camera draw scope

Target `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. All address analysis explicitly uses game view `candidate:view:2:UEU`. This scope is the real camera task draw at `0x1404f59f0`; it is distinct from the script Matrix's 4×4 owner.

The graphics owner stores its model vector at `+0x68/+0x70/+0x78`; each entry is twelve floats, 48 bytes. Drawing duplicates the current entry, or pushes identity when the vector is empty. Camera fields `+0x40..+0x68` contain pivot, offset, scale, radians and clip bounds. The local transform translates by negative pivot, scales entire rows including their translations, left-multiplies Z rotation, translates by positive pivot, then translates by negative offset. The pushed matrix becomes `parent × local`. Helpers `0x140531280`, `0x1405311e0`, `0x1405310a0` and `0x1405308f0` establish that order and floating-point expression grouping. Rotation uses the separately recovered [SSE2 trigonometry](affine_matrix.md), without host sine/cosine substitution.

An ordered clip is transformed by the graphics view, current model and physical viewport through `0x1404c2a70`. It intersects the saved raw scissor. An invalid/unordered clip or empty intersection still draws children under the previous scissor; it does not skip the child task set. A nonempty or zero-width intersection applies its temporary raw scissor, draws the actual parallel children via `0x1404c0120`, and restores the saved scissor. Finally the pushed matrix is popped. [Scissor conversion/cache](motion_scissor.md) retains fractional raw coordinates while comparing rounded cache coordinates; a physical submission uses truncated raw integers. Failed physical submissions do not advance the applied cache.

The portable `LayerCameraDrawScope` owns a preallocated bounded model stack and copies actual frame/view/viewport state. Its narrow submission callback belongs to the renderer; children observe the current model and scissor during their real task draw. It can supply the existing [ScaleView](layer_scale_view.md) `DrawWithCamera` boundary without changing task ownership or inventing a drawable. Constructor allocation occurs before drawing. The stack bound is an authored safety policy; native vector growth is not reproduced. C++ child/submission failures unwind the logical scope before reporting their first failure. If physical restoration fails, the applied cache remains truthful and a later restoration retries it.

A bounded dormant-instruction replay runs 1,000 prepared camera/frame cases, with 1,034,628 unchanged original instructions, 1,000 actual child draws and 362 physical-scissor observer calls. Matrix words, temporary raw/applied scissor words, submitted integers, final applied cache and restored stack/raw state match the portable implementation exactly.
