# VectorFont feature masks

Target: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. All addresses are original executable virtual addresses in the explicitly selected PE view. Original bytes and analysis metadata remain unchanged.

`CompileVectorFontFeatureMasks` implements the native feature compiler prefix at `0x14040b600` through the mask-allocation boundary `0x14040bb36`. It consumes collected records plus checked prepared GSUB/GPOS FeatureList and selected-language metadata. It produces owned tag/mask records and optional actual feature indices. It does not create layout-table lookup schedules or modify glyphs.

Direct instruction recovery:

- Comparator `0x14040b5c0` sorts unsigned tag words, then original insertion order. Four-character ASCII tags have the same lexicographic order in the portable implementation.
- Same-tag records consolidate in insertion order. A later global record sets the global bit and replaces value/global value. A later per-cluster record clears the global bit and keeps the unsigned maximum value while preserving the earlier global value. Only fallback bit one is ORed from later flags; table-search bit four remains the first record's value. Each table's stage becomes the unsigned minimum.
- Zero values are skipped. Global value one uses the common mask at bit one. Other values need their bit width capped at eight, drawn from bits two onward. A request that does not fit the remaining 32-bit mask is skipped; later smaller or common-bit requests may still compile.
- Matching required-feature tags update their earliest stages after the value/capacity checks and before feature lookup. Selected-language feature lookup `0x14040a860` visits that language's feature indices in serialized order. Table-wide fallback lookup `0x140404130` chooses the first matching FeatureList index only when both selected-language queries fail and table-search flag sixteen is present. Required-feature query is `0x14040aa20`.
- If neither table contains the feature, only an explicit fallback flag keeps its record. Compiled lookup-policy bit zero distinguishes that retained missing-feature fallback. The other supported compiled policy bits are preserved as their recovered numeric word; their later glyph-context semantics are not claimed here.
- Global mask starts at two. Private-mask allocation uses the original 32-bit x86 shift counts modulo 32, including an allocation ending exactly at bit 32. Its mask is `1 << end` minus `1 << start` with unsigned wrap. An end-at-32 allocation therefore retains the native low-bit artifact rather than introducing C++ undefined shifts.

Portable preparation uses bounded maps of borrowed four-character tags to preserve first-match indices without an unbounded repeated table scan. Borrowed keys exist only within the compile call and all returned tags are owned. Limits are 65,536 collected records and 65,535 table/selected indices; tags, insertion order, global values, flags and indices are validated before use. Unsupported manual joiner-policy flags are rejected. Allocation failure and allocator-address/ABI parity are outside this prefix's scope.

Four independent ASan/UBSan groups cover original default collection, missing kern fallback, selected-language order, duplicate global/range override precedence, retained table-search/global values, required stages, zero-valued disabling records, capacity exhaustion, x86 end-at-32 masks and malformed metadata. A separate read-only harness runs the unchanged compiler prefix, original CRT sort/comparator and original required/selected/all-feature table queries against bounded synthetic layout tables. Its only observers are the sort's indirect-call guard and two exact private-stack zero operations; no heap allocation, OS callback or initialized game code executes.

All 1,000 native cases match: 5,811 compiled features, 56,299 output words and 21,498,597 original instructions. Output SHA-256: `a6c7d55e91f47b0f8bb11d48740b62ad3f085e4f3823b26c379ca5c43d8f1b5e`. The input includes duplicate table tags, arbitrary serialized selected-language order, required features, missing/table-wide/fallback branches, disabling records and mask-capacity boundaries. The native prefix stops before it clears collected records or compiles lookup/pause schedules.
