There is no authored default findFont callback or fallback font.

## Actual text-task coupling

The TextRender adapter binds real provider services before constructing tasks. Its task owns the empty normal/ruby owner and lends its already-created cached weak-self root; constructing these collections creates no texture or substitute asset. Host preparation `SelectFont` uses that real task and native filtering field `+0x3c8`; `0x140036cb0` stores that field and forwards the same value to the atlas. It does not register a replacement script content method.

MTextRenderImpl destructor `0x140039c40` retires normal/ruby FontInfo first, then cached self ObjectInfo at `+0x430`, then the base glyph atlas. Five focused integration groups verify this order through actual Layer task ownership: wrapper-first retirement retains interfaces until First updates; parent-first retirement closes interfaces before borrowed-view detach. Source roots survive private provider cleanup. If a real callback retires its wrapper or parent, a scoped strong task guard defers active selection cleanup until the callback unwinds and explicitly rejects returning a retired FontInfo. This is an authored lifetime protection for unsafe native reentry, not a measured native reentrant-destructor parity claim.
