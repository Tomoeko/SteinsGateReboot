# Retained Type2 hint event stream

Target: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Addresses are executable virtual addresses. Original resources/hashes are in [vector fonts](vector_fonts.md).

`CffOutline::HintEvents` retains the glyph's executed horizontal/vertical declaration and primary/counter-mask operators alongside raw outline commands. Declaration pairs accumulate into absolute design-space start/end values per call. Mask events retain exact bytes and both axis-count snapshots. Each event's CommandIndex records how many raw commands had already been emitted at that operator; it does not assert when a pending native contour segment uses the new map.

Native dispatch at `0x1403c9b24` selects hstem/hstemhm (1/18), vstem/vstemhm (3/23) and hintmask/cntrmask (19/20). Declaration helper `0x1403c59b0` and dispatch `0x1403c7fd5..0x1403c802b` share width state, keep per-call zero origin and ignore later declarations once a primary mask is valid. Counter masks do not set that primary valid flag. Mask dispatch `0x1403c8cf8` treats trailing operands as vertical declarations before reading bytes; more than one operand after a valid primary mask takes a native skip path, which the authored parser rejects as outside its supported valid-program boundary. Recognized valid-program paths preserve exact byte consumption.

This corrects the earlier raw reader's synthetic late-declaration count; every original glyph has zero late declaration operators. Global/local subroutine execution retains one event stream and glyph-local dictionary routing. Events and declarations own their values; only the immutable programs/private bytes borrow sfnt storage. Counts, executed bytes, recursion, operands, stem sums and events remain bounded. Arithmetic/flex/random/composite operators retain explicit unsupported errors.

All six original CFF fonts were streamed one glyph at a time. Independent FontTools 4.66.1 execution captured raw declaration/mask bytes and pre-operator pen counts. Authored C++ matched all 217,831 glyph hashes: 1,471,158 events (215,711 horizontal declarations, 213,991 vertical declarations, 882,189 primary masks, 159,267 counter masks) and 2,452,500 declared stems. The revised reader also matched all prior 217,831 glyph width/command hashes across 15,742,494 commands, with zero differences. Focused fixtures preserve shared-subroutine declarations, per-call origins, trailing vertical declarations, counter-before-primary state, later primary-mask boundaries, ignored late declarations and event/byte-work bounds. Project conversion/sign-conversion warnings, ASAN/UBSAN and formatting pass.

These are structural design-space events.
