Target: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Addresses below are image virtual addresses; analysis explicitly selected `candidate:view:1:UEU`.

Selected-node constructor `0x1405146b0` dispatches kind4 to `0x1405150e8`. It allocates two independent 40-byte controls at node `+0x228/+0x348`, initially all zero, and an exclusive 176-byte particle owner at `+0x410`. The owner contains the actual emitted-player vector at `+0x60/+0x68/+0x70`; construction leaves that vector empty and the retained preceding matrix at `+0x78..+0x84` identity. This leaf recovers the definition and decoded controls, not emitted-player construction, RNG, clock, geometry, rows or retirement.

Required layer fields and native owner offsets are: `particle` `+4`, `particleMaxNum` `+8`, `particleInheritAngle` `+0xC`, `particleDeleteOutsideScreen` `+0xD`, `particleTriVolume` `+0xE`, `particleInheritVelocity` `+0x14`, `particleFlyDirection` `+0x18`, `particleApplyZoomToVelocity` `+0x1C`, `particleAccelRatio` `+0x20`, and `particleMotionList` `+0x28`. Optional `particleInheritOpacity` defaults to one: `0x140514cb5` initializes ESI to one, `0x140515274` tests actual presence and only a present value replaces ESI before `0x140515289` stores it. Integer mode words retain their signed values. Boolean integer conversion tests the full integer (`0x1404ca782/0x1404ca76f`), then SETNE; it is not low-byte truth conversion.

The motion list is retained as a PSB variant by construction. Actual emission `0x140523359..0x1405233c4` counts its outer array, randomly indexes an element and reads character/timeline strings from element indices zero/one. The portable definition owns those names, preserving source order, empty names and native first-NUL termination; additional pair entries are ignored. It preflights this later-consumed shape within explicit storage limits.

Only outside-screen deletion reads document-root `screenSize` width/height/originX/originY. `0x1405153a1..0x140515524` forms left/top as negative origin minus half extent, right/bottom by adding the extent, then expands each side by five percent of the resulting span. Negative/reversed finite spans are retained. Missing screen data is not consulted in the disabled branch.

Decoder `0x140512e40` leaves hidden controls untouched. Visible slots only enter the particle-control branch when current attribute mask `0x100000` is set (`0x140513f04`). The exact nested key is `prt` at `0x140652a04`. Before reading its low-byte mask, the branch resets ten words to trigger zero, frequency min/max ten, velocity/angle zero, zoom min/max one, range zero. Bits 1/2/4/8/16/32 read `trigger`, `fmin/fmax`, `vmin/vmax`, `amin/amax`, `zmin/zmax`, `range`, respectively. Angles and ranges are copied without normalization or unit conversion. An absent outer mask performs no write, preserving the reused physical control; a present `prt.mask=0` writes the defaults.

`motion-kind4-definition-stage/native_definition.py` executes unchanged constructor and full decoder instructions with real PSB lookup/conversion helpers. Thirty-two constructors and 512 decodes match independent expected words, including screen branches, absent opacity, nonzero integer flags, every control mask group, hidden/absent retention and both physical slots. The run executes 997,537 instructions at 738 distinct PE sites. Heap allocation, bounded CRT memory/string operations and the platform security-cookie check are the only modeled boundaries. Every executed instruction is compared with the loaded original image; native writes are fenced to fixture heap/stack and actual metadata-cache globals. Original on-disk bytes are hash-checked and unchanged.
