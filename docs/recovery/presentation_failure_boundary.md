# Hidden presentation failure boundary

This is a macOS platform correction to the actual hidden transfer owner, not a recovered native failure policy. Original `4c6570` presents the Display `+48` backsurface, ignores the returned HRESULT, adopts its requested synchronization word, and separately queries the Display `+50` pool. Native posthook `4c4930` ends that pool before Present. The actual Layer/root/current-frame producer required by `MacApplicationPump::Present` remains unresolved and the pump still rejects presentation.

`SpritePassPresentation` converts Objective-C exceptions to the existing C++ error boundary. It retains the first exception, operation and kind; a nested or cleanup failure cannot replace them. A scoped phase clears `Presenting` on every exit. Input/tag/geometry rejection remains correctable before transfer mutation. Operational failure prevents subsequent transfer or observational calls, while exact synchronization retirement remains possible.

The real layer setter completes before its cached policy is published. Every failed attempted policy change attempts restoration of the actual previous policy, including an exception raised after the setter changed the layer. If cleanup fails, the owner remains faulted: restoration is not reported as successful. Partial encoding ends its actual active encoder during cleanup. A failure after commit was attempted fences the renderer's existing shared GPU resource domain through a weak platform callback; it does not retain the renderer or make a new device-ready token.

Transfer slots retain the actual producer, command and drawable. Destruction waits only for commands whose actual Metal status reached `Committed` or a terminal status. An uncommitted command cannot complete through a wait and is released without committing it. Destructors terminate if their foreign cleanup fails rather than letting an Objective-C exception escape.

The direct ASan/UBSan proof compiles seven actual source units with their exact recursive headers against coherent, subsequently accepted 442 core. It creates seven hidden owners, requires one genuine queued happy-path transfer, and exercises six clearly authored platform-boundary failures: after a real policy setter, before/after rollback, after real encoder drawing, before actual commit, and after actual commit. It checks actual/cached policy, first cause, phase reset, unchanged synchronization adoption, shared-domain fencing, uncommitted release, committed completion, closed attachments and preserved foreground identity. A separate nested Foundation case preserves an inner C++ cause through outer Objective-C and cleanup failures. Fault injection exists only with the private fixture build flag; no original failure outcomes or GPU fault were captured.

The first passing six-case source and result are retained before the narrow destructor/rollback refinement. Final seven-case results pin the final source. Both generated executables were hash-verified and retired. Hardware display/compositor fidelity, complete native interval domains, actual root Draw/pre/post/pool GPU ownership and application presentation remain open. No original startup, visible window, activation, focus change or speaker output was used.
