# TrueType function and control execution

This component adds CALL, LOOPCALL, ENDF, IF, ELSE, EIF, JMPR, JROT and JROF to the separately validated PUSH/stack/arithmetic domain. It borrows the actual immutable font-definition owner and its complete fpgm byte range. Prep and glyph bytes remain separate borrowed code ranges. The returned operands own their storage; no function or code pointer escapes execution.

The reference is `sgre_steam.exe` SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Native CALL `0x1403B6A01` and LOOPCALL `0x1403B692E` resolve stored function IDs before checking the 32-frame return capacity (`0x1403BC042`). LOOPCALL uses lower count/upper function ID, validates even a nonpositive count, and repeats one return record. ENDF `0x1403B6C03` restores the original range/next PC or the same definition start. The shared operand stack survives calls without per-instruction copies or allocation.

Native lexical skip `0x1403B43B0` decodes PUSH lengths while IF/ELSE count nested branch delimiters. Skipped instructions do not consume the executed-instruction counter. Relative jumps preserve signed 32-bit word targets, allow main-range positive overshoot, and enforce the active function's ENDF upper bound. Native does not impose a lower bound at the definition start or require jump targets to be prior instruction boundaries. EIF itself is a no-op, including outside a paired IF.

The old stack-only API and its admission remain byte-identical. This component retains the original one-million executed-instruction limit and a one-MiB limit per code range. An additional first-party safety bound rejects more than four million lexical scan steps; it is distinct from native instruction counting. Empty entry execution is gated. CVT, storage, graphics-state, IDEF, dynamic definitions and glyph point operations remain unsupported, so this does not close actual prep/glyph hinting or flags-8 rasterization. Nine control, nine unchanged stack and eight declaration sanitizer groups pass. The portable executor matches all 81 original control cases, including 40 calls into the four supplied fonts after their 1,260 FDEF registrations. Those comparisons cover final operands, errors, range/offset, dispatch count and call depth. Prepared native context headers and a bounded size-cache owner remain explicit fixture inputs; original error unwinding runs unchanged. The first missing-size-owner diagnostic is retained separately. This validates the component, not a complete glyph or phone render.
