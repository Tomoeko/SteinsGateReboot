# TrueType operand stack and arithmetic

The portable stack-program component recovers PUSH and 27 stack, signed comparison, boolean and arithmetic instructions from `sgre_steam.exe` SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. It reuses the existing instruction decoder and leaves the font-definition owner unchanged.

Native `0x1403B6116` checks fixed operand counts. Non-pedantic underflow zeros the entire required operand group, including any partial input; strict underflow returns `0x81`. The native stack capacity is `maxp.maxStackElements + 32`. `CINDEX` and `MINDEX` use the preceding stack depth and return `0x86` for invalid references in strict mode. The portable component preserves the non-strict zero/discard behavior.

Arithmetic uses native signed 32-bit words without C++ signed overflow. `0x14039CCB0` performs rounded multiplication/division for MUL; `0x14039CD30` truncates DIV, whose opcode rejects zero denominators with `0x85`. The helpers retain the original `INT_MIN` sign-extension and unsigned-division behavior. FLOOR and CEIL preserve the original low-six-bit masks, including word wrap. Nine focused sanitizer groups and the eight existing declaration groups pass. A bounded prepared-state comparison matches all204 original stack results/errors/offsets, including word extremes and strict/non-strict policy. The588 executed instruction sites (2262bytes) independently match the original PE. These prepared entry-policy headers are not a complete font constructor or glyph execution.

The component owns its returned stack, borrows code and initial values only during execution, and enforces a one-MiB code bound and the original one-million-instruction limit. It rejects function calls, branching, CVT, storage, graphics-state and point operations. It is not connected to glyph preparation and does not admit TrueType rasterization. Full flags-8 interpreter execution, state persistence, composite hinting and rendering remain open.
