The macOS boundary paints those commands and supplies native Unicode text editing. No ImGui code or runtime dependency is included. Search uses an independent bounded scenario catalog on a worker thread; frame code never scans the scenario archive.

The jump action validates the original restore point and resolves its complete checkpoint off the frame thread. Missing states use the same isolated reconstruction worker as command-line jumps. The original `ScenePlayer.exitGame("restart", data)` path consumes in-game requests through ordinary script CALLs. Title requests return the same complete table through original `MotionPanel.onProcess`; `Application.titleLoop` accepts that table directly. This preserves original close/retirement and restore behavior without selecting New Game. Recorder ancestry changes when the request is consumed, rather than while old gameplay is still active.
