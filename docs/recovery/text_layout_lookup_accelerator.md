# Layout lookup accelerator construction

The native lazy cache constructor `0x1403fe9c0` admits GDEF, GSUB and GPOS, freezes their blobs, applies GDEF suppression from sanitized lengths, allocates 12 bytes per lookup, then initializes each record with `0x1403fbac0` (GSUB) or `0x1403fb7e0` (GPOS). This stage recovers the record values, without claiming the preceding native allocations or lazy publication.

Logical executable input is `STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Analysis is read-only and explicitly targets Binary Ninja view `candidate:view:1:UEU`; addresses are executable virtual addresses.

`BuildSubstitutionLookupAccelerators` and `BuildPositioningLookupAccelerators` consume the actual sanitized blob owners. Returned vectors own three 32-bit values per LookupList slot: `GlyphsShift4`, `GlyphsShift0` and `GlyphsShift9`. Repaired offsets affect construction; rejected/missing tables or absent LookupLists produce no records. An erased lookup offset retains a zero record at its original index. The functions borrow table bytes only during construction, so the genuine immutable font pin must remain alive for that call. They do not create a native face, provider callback or successful cache.

Native coverage selection uses single/alternate/multiple/ligature/reverse or positioning lookup format gates, context leading input coverage, chained context leading input coverage after backtrack offsets, and extension target/type traversal (`0x1403fb460`, `0x1403fb500`, `0x1403fb670`). Later input coverages, backtrack and lookahead coverages do not populate this filter. Coverage from multiple subtables is unioned into the same three words. Unknown admitted lookup/subtable/coverage formats contribute no bits. No guessed lookup application or glyph-match behavior is introduced.

Coverage format1 contributes a glyph bit in each plane: `1 << ((glyph >> shift) & 31)`, for shifts 4/0/9. Coverage format2 uses inclusive shifted first/last buckets (`0x1403fa670`), ignores coverage-index words and preserves unsigned subtraction. A shifted distance of 31 or more saturates that plane to `0xffffffff`; shorter intervals wrap cyclically through the 32 bits. Inverted ranges are not silently skipped: native admission accepts them, and the unsigned shifted distance may saturate only some planes. The authored bounded bit loop reproduces these exact values without iterating every glyph in a large range.

Checked byte reads protect construction even if an immutable borrowed-owner precondition is violated. A supported work ceiling of 1,048,576 visited lookups, extension/subtable stages and coverage records prevents repeated-offset work from escaping the portable parser domain. This is an explicit resource limit, not a recovered native cache limit. An accepted table can exceed accelerator work despite cheap count-only admission; a targeted fixture verifies the distinct error and automatic temporary release.

Ordinary `-O1`, strict C++20 warnings, ASan and UBSan pass two groups: point/range mask semantics and admitted/empty/repaired lookup slots plus work bounds. The independent native proof executes original blob/CRT/admission/freeze routines, the exact lookup builders and original blob teardown. Only imported Windows `HeapAlloc` / `HeapFree` are modeled on a bounded fenced heap. Source bytes are mapped read-only; every case checks all allocations retired and the builders preserved fences around the three output words.

The differential exercises every uint16 point glyph, shifted range boundaries/wrap/saturation/inversion, all retained synthetic GSUB/GPOS admission inputs, first-input context/chain selection, multiple-subtable unions, unknown coverage formats, and all ten original fonts with both mutable and initially immutable admission. Original fonts stream once through the first-party reader and are discarded. Retained replay vectors are synthetic; original fonts and raw table dumps are not retained.

Actual cache array allocation/failure, complete lazy publication/teardown, real strong face/font pins and provider behavior remain open. These values are a prerequisite for the real cache, not an effective-cache readiness claim. Glyph application, positioning and the encompassing font-buffer lifecycle remain unrecovered.

The final differential compared 67,969 cases and 349,541 output words, including all 65,536 point glyphs. Native/C++ output SHA-256 is `562cf43917e777db191ed2359e0511426ebd491260b8b5bb10975c80adb4be50`. All 150 retained synthetic cases replay independently through the final executable, and eight malformed CLI cases fail explicitly.

Coherent public ASan/UBSan and portable Release fixtures pass at the 317/292 checkpoint, with retained native witnesses replayed through the public core. Full engine/cache/frame acceptance remains open.
