`MotionPlayerUpdate` is a recovered ordinary update/event producer above `MotionPlayerCommands` and `MotionTimelineClock`. It prepares bounded tag metadata outside updates, owns cursor/sync/align state and pending event records, advances native timing, and exposes actual task Update/PostUpdate/Draw phases. ## Native order and dispatch

MMotion's task base vtable `0x140652e60` has PostUpdate `+0x10 -> 0x14052b0c0`, Update `+0x18 -> 0x14052b0b0`, Draw `+0x20 -> 0x14052afd0`. Its player subobject lies at task `+0x28`, with vtable `0x140652e98`.

Actual Update `0x14050ec60` ignores the task's incoming second argument. It calls the resource-owner interface's vtable `+0x20`, captures its **float return in XMM0**, and preserves that frame delta. It then consumes delayed play; Delay2 returns before remaining phases. Otherwise it resets work-vector endpoints, updates packed-stream state if present, invokes clock/tag traversal `0x14051ffd0`, composes layers `0x14050c550`, clears the player's packet queue, publishes packets `0x14050ad30`, and calls the player completion virtual `+0x18 -> 0x14052c6b0`.

Ordinary synchronous completion (`task+0x1d == false`) immediately drains queued events through `0x14051e640`. PostUpdate independently invokes the same drain, often finding no events. Asynchronous completion checks queue presence via `0x140519b80`, then schedules frame-service callback `0x1404bf770`; it is unsupported by this staged owner. MMotion constructor `0x140529160` selects that mode from runtime byte `0x140a97278`, so synchronous support must not be claimed for every game execution.

Draw thunk `0x14052afd0` adds the player offset and explicitly zeros RDX, discarding the incoming draw argument. `0x140512450` substitutes player draw context `+0x10`, obtains current pointer span `+0x4b0/+0x4b8`, and appends it to the context vector through `0x1402f6520`. This is packet transfer, not proof of final pixel drawing. The authored `Draw()` invokes its mandatory current-packet append service with no invented argument.

## Clock and tags

`0x14051ffd0` stores float32 `frame_delta * speed` at `+0x1a4` and clears transient align `+0x27d`. Initial tag pending `+0x193` triggers a seek. On a negative delta with zero tick, both tick/evaluation begin at lastTime. Assigned tick flag `+0x191` prevents increment during that update. Native composition clears `+0x191/+0x192` only at its tail, after first-frame displacement handling, before packet publication; the next update advances ticks. Stop with pending initial evaluation still processes that pending evaluation. Nonlooping forward end retains overshot tickCount and clamps evaluation to lastTime; nonlooping reverse end clamps both to zero and stops Playing.

Forward loop crosses the outgoing lastTime with forward traversal, seeks loopTime, repeatedly computes float32 `(tick-lastTime)+loopTime`, then traverses forward to the wrapped tick. Reverse loop traverses back to loopTime, seeks lastTime, repeatedly computes `(tick-loopTime)+lastTime`, then traverses backward to the wrapped tick. Intermediate whole scalar wraps do not separately redispatch all tags. Align or sync can interrupt boundary processing before wrapping.

Real seek `0x140511640`, forward traversal `0x140518160`, and reverse traversal `0x14050a6b0` operate on tag atom `+0x260`, count `+0x25c`, current index `+0x270`, and adjacent times `+0x274/+0x278`. Tracks use a terminal frame; current index clamps to count-2. A terminal time equal to lastTime is valid: an exact terminal seek selects that index and clamps back to the penultimate frame, while forward traversal never enters the terminal index. Bounded preparation permits terminal time at or beyond lastTime; empty/one-frame priority tracks and nonempty one-frame tag tracks remain unsupported. Forward enters a tag when evaluation reaches its next boundary. Reverse enters the previous tag only when evaluation is strictly below the current time. A seek selects the containing tag and can queue its action even if evaluation is beyond that tag's exact time.

Type1 tag content requires `align`, `sync`, and `action`. Seek applies Align only at exact tag time; forward/reverse apply it when crossing. Align sets tick/evaluation to tag time and marks `+0x27d`. Sync always sets those words to tag time, marks persistent wait `+0x27c`, retains Playing=true and queues a Sync record before its Action. Sync waiting blocks later timeline advancement while composition/publication continue. Incoming ordinary selection `0x14051bd50` clears that wait; numeric tick assignment alone does not. Nonempty Action queues an Action record with empty layer name. Boolean conversion `0x1404ca6d0` tests the full decoded integer (`TEST EAX,EAX` at `0x1404ca782`, `TEST RAX,RAX` at `0x1404ca76f`) before `SETNE AL`; every nonzero integer is true. Serialized float32/float64 compare against zero with `UCOMISS` at `0x1404ca759` and `UCOMISD` at `0x1404ca717`; their unordered branches explicitly return true. Both signed zeros are false; subnormals, infinities, quiet NaNs and signaling NaNs are true under the measured masked-exception, no-flush MXCSR domain. The portable double nonzero comparison preserves that result after float32 widening.

Frame-cursor/variable/layer preparation follows tag traversal. Native oracle boundaries observe seek at priority output `0x140515c80`, forward after tags at `0x1405183c0`, and reverse after tags at `0x14050a8f4`. Mandatory `PrepareFrames` receives the resulting evaluation state and can enqueue real layer actions after tag actions. It must supply actual preparation; the existing scalar evaluator is not silently asserted to produce the complete native player hierarchy. Composition and publication are separate mandatory callbacks in native order.

Event drain `0x14051e640` detaches the vector at `+0x2e8` before invoking any listener. Event kind0 invokes player `+8 -> 0x14051b4e0`, which visits live listener `+8` callbacks with layer/action strings. Kind1 invokes player `+0x10 -> 0x14051b550`, visiting listener `+0x10` sync callbacks. Events enqueued during delivery remain in the fresh pending queue. The authored owner uses two reserved vectors to preserve that ownership and ordering without allocation in ordinary updates. Queued strings borrow immutable resource/layer owners through delivery.
