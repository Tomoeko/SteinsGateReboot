## Native preparation and order

Layer metadata `0x1405146b0` retains the exact PSB `label` pointer at node+0x10, `frameList` atom at +0x50 and optional per-layer parameter target at +0x20. Frame decode `0x140514460` resets the previous decoded frame's owned curve/path handles, reads time/type, marks type0 hidden, type2 static and type3 tween, and reads required content mask for present frames. Mask `0x40000` reads required `act` text into frame+0x108. Attribute preparation `0x140512e40` uses actual source/icon strings and decoded attribute masks; the existing scalar preparation supplies these immutable values for the accepted static subset.

- Seek `0x140511640` scans first exact time or previous-to-first-greater and clamps to count-2. It decodes/prepares current and following frames into slots +0x110/+0x230, sets active slot +0x350 to zero and marks frame dirty +0x40. Source binding `0x140515d40` occurs before the action. A seek action queues only when current frame time exactly equals evaluation and its mask contains `0x40000`.
- Forward `0x140518160` crosses at equality, toggles slots, decodes the next following frame and queues every entered action in order. After all crossings it prepares changed slots and binds the final current source pair once. No crossing means no new source binding.
- Reverse `0x14050a6b0` crosses only below the current time, toggles/decodes the new current slot and queues every entered action in reverse traversal order. It prepares changed slots and binds only after all actions from that traversal are queued.
- Actions use the selected node's exact label, retrieved by `0x140518d50`, rather than a synthesized parent path. Native event strings use the C-string boundary. Action mask presence queues even an empty `act` string; no nonempty test is present in the frame paths.

The source accepts type0 layers with finite sorted zero-origin tracks, types0/2 frames and a terminal at or beyond lastTime. It requires matching raw/prepared time/type/label data, actual present-frame source/icon strings, bounded act metadata and empty timeline variables. The resource-backed constructor admits proven type3 tweens; type1 remains unsupported. Both interfaces reject per-layer parameterization, ground correction, other layer kinds, mesh/unresolved attribute behaviors and parameterized/packed timeline playback. Traversal consumes recovered action mask `0x40000` from published sample unresolved bits. It samples the actual selected immutable prepared frame through the existing helper, now exported as `SamplePreparedMotionFrame`; it does not use a stateless interval search that would change duplicate-time seek behavior.

Every frame sample and queued string retains its resource owner's lifetime through use. Callbacks may not reenter traversal; aggregate frames and depth are bounded. Failed traversal invalidates the sample publication flag. All ordinary traversal/sample work reuses startup storage. Frame/variable/action preparation and source services still need genuine selection/resource-owner adapters before a complete Motion binder can call them.

## Native string ownership and callback reentry

Native queue entries are 24 bytes: kind plus raw label/action pointers. Current `act` comes directly from PSB string accessor `0x1404cacf0`; current label is the borrowed node+0x10 pointer. `0x14051e640` detaches only vector allocation ownership, forwards those raw pointers through `0x14051b4e0`, and frees vector storage afterward. There is no queue-time or detach-time string copy or resource retain.

Listener vtable `0x1405f98e8` has Action `0x140273d20` and Sync `0x140273ef0`. Action checks wrapper event-forwarding flag +0x102 and receiver validity, then pushes label/action through `0x140228510` → `0x1402241d0` → `0x14024cd90` → `0x14024fe30` before invoking `onAction`. The intern table finds an existing owned SQString or allocates a new one, copies bytes with `0x1405ac650`, terminates it and stores its length. Thus the current callback's VM string arguments are owned independently before the callback can change selection.

That per-invocation copy does not establish validity of later raw entries after a callback switches or unregisters resources. The exact PSB/manager/script pin maintaining those later pointers remains unrecovered. Portable event views still require their immutable source owners alive through the complete detached delivery; this source does not invent a VM self root or silently add a resource pin. A binder must prove the actual resource-owner bridge or retain this path as unsupported. Action listener delivery walks the live vector directly at0x14051b4e0: after each callback it advances the8-byte cursor and rereads end+0x2b0. It neither copies the listener vector nor adds a retain. Listener mutation, owner finalization and raw-event resource lifetime remain open.
