# Input state and native script bindings

Reference: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Addresses below are executable virtual addresses. The authored input core contains no window, keyboard, controller, or cursor APIs.

`InputHub` registration is `0x140241f00`; its Object-derived constructor `0x14023f370` creates `MSingleInputHub` through `0x1404f1cc0`. This target fixes eight owned `MInput` states. Count reads that limit (`0x140299900`); device selection clamps only the upper index (`0x1404f3d20`). Negative selection would read outside native storage and is rejected by the rewrite. `inputAt` (`0x14023fd20`) creates a fresh Object-derived Input wrapper for the selected device and a separate mouse owner. With configured frame services, the wrapper release only marks its actual Driver Common-parallel task Retire (`0x14023f2b0`); the task retains Hub state until physical traversal invokes `0x1404f2090`. Existing device views borrow that task lifetime. Each inputAt wrapper separately owns its mouse and VSync registration; its release directly retires those resources (`0x14023f250`). The explicit portable mode without frame services retains its direct owner lifetime and is not a platform sampling claim.

`0x1404f4200` copies buttons and all 256 keyboard bytes, shifts their previous values, retains stick/trigger values under this target's zero threshold defaults, accumulates the left-stick cursor by five logical units per call, and applies centered driver extents when available. Repetition modifies the previous state to produce a new pressed edge. A group repeat timer tests whether any selected button is held; raw keyboard timers operate independently. Native integers used as repeat durations are sign-extended into unsigned 64-bit fields, including negative script values. Floating conversion, subtraction, carry into the interval, and clamping to zero stay separate. Queries `0x14023fe90/fea0/fec0/fe50` recover key masks, newly pressed/released masks, and newly completed combinations. Direction lookup uses the 16-word table at `0x140651b60`. The first hub sample processes device zero twice (`0x1404f4760`), suppressing its initial edge and advancing its timers/cursor twice; later devices are processed once.

Native `0x1404f3960` prepares 312 named compatibility sources and 25 named targets from tables `0x14096ad40/0x14096c0d0`. Default conversion (`0x1404f2c00`) copies 19 scan-key and three virtual-key mappings from `0x14096c270/0x14096c360`. Source names fold to upper ASCII and target names to lower ASCII in the native C locale. Embedded NUL ends the name. Add (`0x1404f24e0`) appends duplicates, accepts unknown/empty targets as zero, and returns false for an unknown source. Keyboard sampling ORs both logical and controller button masks and excludes Alt+Return (`0x1404f4760`). The first-party tables retain the original binding vocabulary without depending on Windows headers; future platform samplers must translate host events into these identifiers explicitly.

`Input` registration `0x14023fee0` places KEY and ControllerType in the separate shared VM constant table. They are not root-table fields. InputHub static conversion methods affect one owned session mapping service. Native property access reaches actual hub/device state through the Object adapter. Authored capacities and finite-coordinate preflight bound unsafe native cases; these guards do not claim native malformed-input equivalence.

## Mouse and desktop controls

Mouse sampling hook `0x1404f3e80` converts a supplied client point to integer normalized coordinates by float subtraction/division, double multiplication by 10,000, float conversion, then truncation. Invalid/other-window points store 32,768 in both components. First sampling and the sample following an outside point prime previous positions/buttons. The position query `0x1404f3580` divides valid integer coordinates through double arithmetic; movement retains integer normalized-coordinate differences. Button queries read native fields +0x40/+0x44/+0x48. Wheel query `0x14023fbb0` reports sign only. The independent enter flag is updated separately; `0x14023fe80/23f9e0/23fa00` recover inside/entered/leaved. A separate native mouse object belongs to every inputAt wrapper.

A CPU-only native oracle supplies cursor/client/window observations and input bytes without calling OS services. All 800 sequential samples match 28,000 bytes, SHA-256 `7033246e4173f372dec570f2592fa58145f08c95961dea741e6729609d4d6fcf`. Cursor setter `0x1404f4670` performs float half-size multiplication/addition followed by integer truncation and directly passes that client-derived point as an absolute cursor request; it does not add the client origin or clamp. All 1,000 captured request calculations match 8,000 bytes, SHA-256 `3a406eec306e23e4b51ecd8831b8e5b4763d0ab925b01306b5f5f0ff9ac3c7be`. Authored request planning never moves the cursor. The script setter requires an explicit client reader/request sink; tests use a private recording sink and do not touch hardware.

The desktop target registers literal RET setters for analog sensitivity/dead zone/front touch, disconnect, touch/sensor enabling, and soft keypad. Their fixed getters are retained rather than interpreted as functioning device controls: sensitivity integer zero (`0x14004b530`), dead zone/horizon float zero (`0x14023f580`), touch false (`0x14004b570`), accelerometer true (`0x140073fa0`), and acceleration (0, 0, float bits 0x411ce80a) from `0x1404f24d0`. These are executable-derived compatibility behaviors, not measurements of host sensors.

Independent reclamation fixtures cover wrapper collection, physical Hub retention until Driver retirement, surviving per-view mouse state, registry reuse, external-root protection and cycle finalization. Class metadata is externally rooted. Frame-owner mutation and retirement require the actual serialized owner thread outside sampling or traversal.

## Platform sampling and remaining checks

The native Hub registers its sampling hook during `0x1404f1cc0`; each mouse registers a separate hook through `0x1404f1fa0`. Sampling runs in the actual post-wait VSync phase, independently of the Driver task's empty Update/Draw methods. The authored binding takes the real Looper and Driver Common-parallel owner before script construction. Root `funcKeyPressed` and `altEnterPressed` use a separate same-phase snapshot and never consume it; Alt+Return's original shift/sample/getter sequence passed 61 sequential native frame vectors.

The macOS boundary owns window-scoped tracking and read-only focused CoreGraphics keyboard/button sampling. It observes controller presence through an enumeration-only IOHID manager; an actual connected controller remains an explicit unsupported sampling domain. Keyboard-only Hub conversion uses recovered scan identifiers, while configured layout-specific virtual keys remain gated. Shared wheel/button output is consumed by the Hub and borrowed by independent mouse clocks. Hidden tests verify actual focus loss, cursor bounds, no-controller observation, tracking retirement and unchanged foreground/visibility; they do not compare focused hardware responses.

Controller axes/buttons, vibration, aligned touch/angle queries, focused keyboard-layout translation and native ANSI text input remain open. Native `getWMChar`/`getDownKey` have distinct event-pending and VSync-published state: `0x1400487b0` appends only the low byte of the native WM_CHAR operand, while `0x140048ef0` publishes and clears it. The original creates an ANSI window, so Cocoa UTF-8 is not assumed equivalent. Native close-triggered BackPulse is also distinct from a generic close request. Preserve the hidden, silent, nonactivating policy during platform observations.
