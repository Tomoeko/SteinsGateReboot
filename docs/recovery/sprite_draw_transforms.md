The native matrix source is the current render record and global graphics model stack. `0x1405320d0` resolves identity, explicit, or projection×current-model rows when the native draw prepares its shader; `0x140530890` supplies the fourth row. The original authored Metal submission copied one containing matrix into every draw's constant segment. That could not represent several live camera/model scopes within one batch. `SpritePassDraw::TransformRegisters` now owns an optional sixteen-float shader snapshot captured while that draw's genuine model is current. The backend copies the selected value into its actual free upload slot; absence retains the existing containing-submission matrix behavior. The constant layout and shaders are unchanged. The caller still resolves the recovered identity/explicit/combined mode; this field does not infer a native render record or camera.

Nonfinite explicit snapshots reject during input validation, before upload-slot writes and command submission. This is authored safety within the admitted finite-transform domain, not a recovered native exception policy. Draw records own their matrix values; geometry continues borrowing caller storage until the backend's existing immediate copy completes.
