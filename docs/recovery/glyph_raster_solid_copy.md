Words encode B/G/R/A at bit positions 0/8/16/24 independently of host byte order. Prefix area starts at `0x20000`, adds native modulo-32-bit deltas, shifts arithmetically by eight, applies rule mask `0xfffffffe` or `0x3fe`, takes the native absolute difference from 512, and clamps to 512. Weight is the low-32-bit product with `opacity << 7`, shifted by 16 (`0x1404a10d3..0x1404a115b`).

Four-pixel active groups take the native per-pixel path: each channel computes `source * weight + destination * (255 - weight)` and then `(weighted + (weighted >> 8)) >> 8`. The executable omits an endpoint correction. Fully covered white therefore becomes 254 in those processed groups. Gaps between active runs bypass multiplication for weight 255 and copy the original source byte, producing 255; zero-weight gaps preserve destination. These paths are observable behavior, so they cannot be replaced with one idealized division or an unconditional zero-opacity skip. Higher-level style rejection/optimization is separate from this selected kernel.
