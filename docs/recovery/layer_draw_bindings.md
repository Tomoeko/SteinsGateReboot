The DrawingProxy stores an externally rooted canonical weak ObjectInfo of its target. An already-expired weak argument is copied as that original weak wrapper, rather than replaced by resolved null. Immediate scalar targets remain immediate values. The task keeps neither a strong target nor a strong script wrapper/parent. Detached visibility is false; native opacity setters/getters dereference the stale task without a guard, so the authored adapter rejects that unsafe domain explicitly.

It passes the complete draw argument and opacity words. Non-instance/null/expired targets set `the object is not a class instance`; wrong class tags set `invalid type tag`.
