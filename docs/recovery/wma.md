# WMA Standard recovery

The game supplies 15,019 WMA Standard channels with format tag `0x0161`, 16-bit decoded samples, and no codec extension bytes. 14,817 channels use 44,100 Hz; 202 use 48,000 Hz. No supplied channel uses WMA Professional. `ReadSoundArchive` establishes encoded ranges and decoded-packet cumulative-byte (`dpds`) tables; it does not decode WMA samples.

The runtime sound binding now forwards profile31 only when its containing application explicitly configures `SoundBufferedDecoderProfile::VerifiedWmaOptions31`. The one-argument configuration leaves it unset. Missing resource extension bytes never synthesize a codec profile. Native game code passes the original format, encoded buffer and dpds directly to XAudio2 at `0x140392363`/`0x140392541`; the downstream Microsoft implementation is a separate research oracle, not a recovered game-owned PCM decoder.

The exact first-scenario voice PSB has SHA-256 `0688a443f478557df24b49ec6fd2f1b9f99451c6fecb61f0cb88930b3c037d40`. Its unchanged18-byte format,19,331 encoded bytes and13-entry ledger pass the actual resource reader, cue, source and macOS offline pool. At44,100Hz mono, all167,936 output frames match the independent native buffer-only result within4.1723251342773438e-7, below the preselected1e-6 bound. At48,000Hz stereo, the pool consumes all167,936 source frames and produces347,808 finite nonzero samples; this establishes receiving and lifetime safety, not native XAudio2 resampler/filter parity. Both cases run with manually discarded output and no hardware audio device. Archive retirement, retained idle nodes and source-first callback detachment also pass.

`WmaBitReader` now provides checked MSB-first reads/peeks/skips with explicit bit positions and no consumption on failure. `ReadWmaPacketHeaders` reads the established two-nibble prefix and converts dpds differences to per-channel decoded sample counts. It validates complete packet extents, allocation limits, modulo-16 sequence continuity from the beginning of a complete resource, and decreasing/partial-sample ledgers. Codec extension variants fail explicitly.

## Bounded packet streaming

`WmaStandardStreamDecoder` owns cached transform/band/codebook setup, fixed coefficient/compact/time/frame/overlap/reservoir workspaces and a 17-frame packet-output array (272 KiB at stereo 2048 coefficients). `DecodePacket` consumes one original packet and its cumulative decoded-byte entry; its returned interleaved float span borrows this decoder until the next call. Sequence/order/final ledgers and work bounds are checked. A parsing failure closes the decoder; successful completion reaches the exact original final sample count. Construction prepares heap storage; subsequent successful packet calls do not grow containers or prepare transforms.

A research-only C++ allocator counter observes zero `operator new` requests during every successful packet call across all three format samples and the fractional-ending sample.
