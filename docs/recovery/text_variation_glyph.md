# Vector font variation glyph query

`VectorFontVariationMap` prepares a borrowed format-14 query from the genuine `resource::SfntFont`. The reader and its immutable bytes must outlive the query. Preparation selects the first original-order `(platform 0, encoding 5, format 14)` map, validates its payload once, and allocates no table copies. A missing map, selector, codepoint pair, or glyph zero returns no value. The query does not install native font callbacks or manufacture a font owner.

## Executable evidence

Logical target: `sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Analysis explicitly targets Binary Ninja `candidate:view:1:UEU`; original bytes and metadata remain unchanged.

Font-function setup `0x1403a6f50` installs variation callback `0x1403a7600` through setter `0x1403a5450` at font-functions offset `+0x138`. Its userdata begins with the borrowed face pointer. The callback calls `0x14039af00` with full 32-bit codepoint and selector keys. A nonzero returned glyph writes the output and returns true; zero returns false without writing the output.

The FT query requires a nonnull face and selected map whose encoding word is `unic` (`0x756e6963`). It calls discovery `0x1403a14b0`, then dispatches through the variation class callback at `+0x28`, passing the selected Unicode map independently. Discovery walks face charmaps in their original order and considers only platform 0/encoding 5. It asks the face driver for the original `tt-cmaps` service, calls its cmap-info procedure, and accepts the first successful format-14 report. The portable constructor uses the matching metadata already recovered by `SfntFont`; it does not choose a different Unicode base map.

The TrueType driver class at `0x14060c130` uses `0x1403b1cc0` to find the SFNT module and delegate through its interface. The CFF class at `0x14060d480` uses `0x1403c4110`; its `tt-cmaps` service at `0x14060d568` forwards through `0x1403c3c20` to the SFNT module. Module lookup `0x14039b3d0`, service lookup `0x1403a23e0`, and the original string comparator `0x1405ad360` resolve the actual descriptors. The SFNT class `0x14061ff88` uses interface procedure `0x1403e64f0`, service list `0x140620000`, and cmap-info procedure `0x1403e7190` stored at `0x14061fd08`. The class-info procedure reports the format through class offset `+0x60`.

Format-14 class `0x14061fdf0` has object size `0x40`, initializer `0x1403e3280`, level-dependent validator `0x1403e32c0`, variation-index callback `0x1403e3660`, format field 14 at `+0x50`, and cmap-info procedure `0x1403e3650`. The initializer retains a borrowed table pointer and selector count; the query does not modify it. Selector search `0x1403e9850`, default-range search `0x1403e9650`, and explicit-map search `0x1403e96f0` use unsigned full-width keys against serialized 24-bit values.

## Recovered behavior and bounds

A matched selector supplies separate default-range and explicit-mapping offsets. The callback first searches the default ranges. A default match returns the selected Unicode cmap's character-index result immediately, including zero. It does not try an explicit entry after that zero. An explicit entry is queried only when the codepoint is outside the default ranges or the default offset is zero. Its stored unsigned 16-bit glyph ID is returned directly, without the nominal callback's face-glyph-count clamp. The synthetic `0xffff` explicit glyph for an eight-glyph font verifies this distinction. Default queries use the selected base map even when an alternate map contains the supplementary character.

The level-0 native validator requires a ten-byte header, a declared length within the containing cmap, selector records within that declared length, nonzero strictly increasing selectors, and each nonzero referenced offset strictly below the declared length. Selector values are not restricted to a guessed Unicode variation-selector set. Default ranges must be sorted and nonoverlapping with inclusive ends below `0x110000`; explicit codepoints must be sorted, unique, and below that same bound. Level 0 does not reject explicit glyph IDs against the face glyph count.

Native referenced record-array bounds use the containing cmap's end, even when an array extends beyond the declared format-14 length. The portable parser preserves this observed bound. Header/record reads decode bytes explicitly, check subtraction-based bounds and stride counts, and report contextual exceptions. Preparation caps the total visited selector/default/explicit records at 1,048,576 to bound repeated-offset work. This is an authored safety limit rather than a recovered native semantic restriction. Malformed candidate maps fail explicitly; native face construction that rejects/skips malformed charmaps is outside this borrowed-query boundary.

The [OpenType cmap specification](https://learn.microsoft.com/en-us/typography/opentype/spec/cmap) names format-14 selector records, default ranges, and explicit mappings and supplies their byte layout. Executable analysis and native differential results determine lookup priority, discovery, selected-map isolation, validation bounds, input width, and missing-glyph policy. No Unicode version or host font behavior is assumed.

## Validation and integration

The actual native callback, first-party C++ query, and independent table model match for 2,372,739 queries (18,981,912 compared bytes), streamed output SHA-256 `d8486ff2da5e6b8d099ebb5dc4fc80005f1451b382e115f37314690b86c8e2d4`. Seven authored profiles cover complete Unicode-range axes for explicit mappings with format 4 and default mappings with format 12, a BMP default-format-4 axis, discovery gates/order, absence, containing-cmap bounds, and the preferred Windows Unicode map. All ten original fonts cover every stored explicit mapping and every default-range codepoint plus neighboring, missing, and unsigned probes. Three strict O1 C++20 ASan/UBSan groups include ten malformed-table fixtures; six malformed driver requests fail explicitly, and empty requests pass. Repeated-offset work fixtures accept 1,047,039 visited records and reject 1,049,088. Private receipts retain callback/service/class ranges, executable/font hashes, input/output hashes, and bounded direct samples. The native harness uses bounded caller-owned face/module/library/charmap contexts, chooses the genuine TrueType or CFF driver class from each font signature, calls native class initializers and successful level-0 validators, and runs the real service discovery path. Original code, class/service descriptors, and font cmap bytes are read-only. No service callback is stubbed. Output fences, untouched failure sentinels, stack/cursors, input immutability, and persistent context fields are checked. Fonts are streamed one at a time through the existing first-party resource reader and are not retained.

At normalizer helper `0x14040cb10`, a following codepoint in `0xfe00..0xfe0f` or `0xe0100..0xe01ef` enables variation lookup. The helper clears the current glyph record's four-byte word at `+0x0c` before passing that word to callback `+0x138`. Failure branches to separate nominal callback `+0x130` queries; success reaches two-input/one-output emission through `0x1403a6520`. Selector consumption, cluster propagation, allocation, and publication at that boundary still require recovery.

Integrate the prepared query beside the nominal query only after pinning a genuine font resource and reader for the caller's lifetime. Map a missing result to the original false/untouched-output callback policy, using the actual normalizer callsite's initialization and fallback order. The supported boundary uses constructor-preferred Unicode base maps. Native face creation/charmap filtering, symbol/default-map profiles, font lifetime, recursive decomposition/emission, buffer growth/error publication, mirroring acceptance, recomposition blocking, final glyph positions, and full shaping remain open.

Coherent public sanitizer replay matches 272 retained native samples across 17 profiles, streaming original fonts without retaining copies. The278/253 checkpoint passes integrated and portable Release fixtures. This does not complete normalizer selector consumption or establish a live pinned font owner.
