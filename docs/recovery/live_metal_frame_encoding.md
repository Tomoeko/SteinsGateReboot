# Live Metal frame encoding

`SpriteFrameEncoder` borrows an actual prepared `SpritePassRenderer` and its serialized graphics owner. It opens a real Metal render encoder at Begin, copies each admitted draw's geometry and shader constants into an actual free upload slot before Append returns, and permits the live camera traversal to bind physical integer scissors between those draws. End ends encoding, commits the real command buffer and then publishes its submission identity. Abort discards uncommitted work without publishing a nominal frame.

The shared graphics resource owner fences concurrent Submit, upload, pipeline preparation, mutable binding/copy access and presentation current/latest callbacks until encoding ends. Actual target selection and allocation preflight this shared owner before changing the selected identity or allocating a target; null, same and changed target requests all reject while it is active. A rejected drawing operation retains its first error; End cannot commit it. Foreign-thread calls reject before mutating that error state. A retired renderer is detected through its existing weak receiver lifetime. The facet retains GPU resources required to abandon uncommitted work without dereferencing a retired upload-slot pointer. Destruction requires its serialized owner thread. An ambiguous commit exception faults the shared graphics resource owner rather than allowing any sibling target or presentation to report success. Retirement waits only for commands that reached the committed state; an uncommitted command retained after a rejected commit is released without an invalid completion wait.

Portable `LayerCameraDrawScope` supplies the actual live frame state and native integer scissor operation; this backend does not invent a root Draw, scene owner or OS clock. Both the legacy submission and live encoder creation consume the recovered default raster descriptor (`0x1404c56e0`, executable SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`). Physical Metal scissors intersect that integer rectangle with the actual target. Empty intersections remain explicitly unsupported in this initial domain. Per-draw scissor overrides reject during live encoding.

The direct 16-unit ASan/UBSan proof pins 59 source/header/library inputs. Two real completed offscreen submissions produce 32 independently expected pixels. It checks actual camera apply/restore, shared nested fractional-cache behavior, immediate caller and paged-heap uploads followed by source reuse, shared-context exclusion, rejected uncommitted frame preservation, retired-renderer lifetime and the real presentation source callbacks. The presentation guard test creates no window and requests no drawable. Earlier passing inputs and syntax errors are retained separately.

This validates authored Metal behavior, not a native Direct3D pixel comparison. RawTex, copied-destination and additional layouts retain their existing validation but are not newly accepted by this fixture. Empty scissors, the full eight-record render owner, Display prehook/posthook, original root traversal, GPU failure injection and application Present/clock integration remain open. No original game scene, visible window, speaker output or whole-game milestone is claimed.

Apple documents [render encoders](https://developer.apple.com/documentation/metal/mtlrendercommandencoder?language=objc), [scissor binding](https://developer.apple.com/documentation/metal/mtlrendercommandencoder/setscissorrect(_:)), [command buffers](https://developer.apple.com/documentation/metal/mtlcommandbuffer?language=objc) and [retained resource references](https://developer.apple.com/documentation/metal/mtlcommandbuffer/retainedreferences?language=objc). The next join is the recovered actual frame owner and its camera/cache/root phases driving this encoder.
