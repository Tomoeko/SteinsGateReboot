# Original locale initialization

Target: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Addresses are executable virtual addresses; source recovery and validation leave the original unchanged.

Native bootstrap `0x1405ab4b0` first installs country `JP`, language `ja` and time-zone offset 540. It then calls [GetUserDefaultLCID](https://learn.microsoft.com/en-us/windows/win32/api/winnls/nf-winnls-getuserdefaultlcid) and searches the 156 ordered 24-byte records at `0x1408f7b20`. An exact identifier replaces the language/country; no match preserves the original defaults. The catalog contains 77 distinct language codes and 110 country codes. Its identifiers and names are recovered data, not a dependency on a Windows locale implementation.

Country setter `0x1405363a0` and language setter `0x140536400` retain their strings and pack the first two unsigned bytes as `(first << 8) + second`, or zero for a shorter string. Longer codes retain their full text while the integer still uses only its prefix. System registration `0x140285f50` exposes country string/int through `0x140283dd0`/`0x140283dc0` and language string/int through `0x140284130`/`0x140284120`.

Portable `ResolveOriginalWindowsLocale` follows that catalog and fallback. `ResolveOriginalHostLocale` matches supplied language/country codes exactly, with the same unsupported-locale fallback. This pair mapping is the authored portability boundary; it is not evidence that two operating systems choose identical regional preferences. The macOS service copies codes from [NSLocale.currentLocale](https://developer.apple.com/documentation/foundation/nslocale/current?language=objc) into owned UTF-8 strings at initialization. Foundation types remain in `src/platform/macos/`. System callbacks require configured bootstrap state and return immutable VM strings and packed integer words. The game continues to choose its language through original `getSystemLanguage` bytecode; no replacement language-selection helper is installed.

A private CPU harness executes the original bootstrap, all original string/copy/packing helpers and security-cookie checks. Its only substituted boundaries are controlled GetUserDefaultLCID and GetTimeZoneInformation inputs. All 156 records and three unmatched identifiers match the authored selection and packing over 641,425 unchanged native instructions; output SHA-256 `53f2cd863c419f2722efd05f0ffe14a08a208c59c722180c72257737d4c8dd73`.
