# Metal copied-destination additive pass

The offscreen renderer implements the narrow native PS1205 pair with either measured VS1 indexed XY/color/UV or VS4 nonindexed XY/UV input. The [readable HLSL certificate](copied_additive_shader.md) reproduces all 1,188 original DXBC bytes, SHA-256 `25b33897c9c9dd667f06eae6ad8b59e1f8cbcd902345bf443d87906167395450`. The exact executable identity is recorded there. Readable Metal preserves the shader's source sample, copied sample, color multiplication, capped addition and opacity interpolation operations; this does not establish cross-API floating-point identity.

Source texture/sampler occupy pixel slot 0 and the actual copied destination occupies slot 2. Each draw snapshots the generation-checked borrowed copied texture handle and `screenMulOffset` affine. The fragment cb0 float4 is copied into a separate per-draw constant range, rather than sharing the VS matrix/color range or allowing a later draw to overwrite it. Both texture owners and their backend must remain live through preparation/submission. Metal commands retain submitted physical resources, so release after commit remains valid while future stale-handle use rejects. Native program index is part of the pipeline cache key, keeping PS1205 separate from ordinary PS240 even when their remaining operations agree.

Native `0x140531550` / `0x1405316c9` select blend state 10 for family `0x100` when the prepared material blend flag is enabled, or state 7 otherwise, in phases 0/1/6. The six-word rows at `0x140653350` are `{1,2,1,1,1,2}`: RGB Add/One/Zero and alpha Add/Zero/One. State 10 therefore copies the shader's computed RGB and preserves the current rendering target's alpha. State 7 disables blending and writes shader opacity as alpha. The copied texture's alpha is unused. A separate unchanged-instruction oracle verifies 36 phase/flag/write-mask/family combinations over 6,462 original instructions, including write-mask suppression and subsequent native blend-state restoration; trace SHA-256 `c663df800bc14a8d9c5468c7920dcd4bfd87e091853037a7ece60d3ecaf06598`. GPU service boundaries are observations, not substituted pixel calculations.

`SpritePassLoadAction::Preserve` loads the current target instead of clearing it, matching the copy-then-draw ordering of the original routine. The default remains `Clear`; an authored guard rejects preservation before any initializing submission. Original source rendering, region copy and additive draw share one command queue, with no intermediate wait. Captures and waits occur only in validation. The backend admits actual pixel slots 0 and 2; slot 1, vertex-stage bindings and other auxiliary programs remain explicit errors. CPU prepared-row restoration still makes no physical unbind call: the retained slot-2 hardware binding is independent of a restored null row entry.

Four strict Apple-Clang ASan/UBSan groups pass with Metal API and GPU validation enabled. They compare 384 synthetic RGBA output channels across both vertex layouts, states 7/10, an offset 2-by-2 copied region, partial opacity, RGB saturation, separate per-draw copied coordinates, unchanged pixels outside the draw and zero write masks. Mixed RGB values allow one byte of normalized rounding difference; preserved target alpha and untouched pixels compare exactly. The fixtures also verify real borrowed-owner binding/restoration, pipeline cache separation, close-after-commit, stale/missing/wrong-format destination rejection, finite constants, unsupported slots and a library missing the copied fragment. Existing sprite, mutable texture, RawTex and copied-region suites pass against the same staged renderer.

This is an Apple Silicon physical sampling/blend/queue/ownership proof with independent expected pixels and native bytecode/CPU provenance. Windows GPU differentials, whole motion frame/state-stack integration, stencil/multipass work, auxiliary slot 1, immutable-cache borrowing and other copied blend/filter programs remain open. The renderer requires a prepared live RGBA copied owner and recovered finite constants; it does not invent a missing scene or resource lifetime.
