# TrueType persistent state slice

The original `sgre_steam.exe` SHA-256 is `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. This slice recovers scalar graphics state, axis vectors, storage, equal-ppem CVT access and rounding from its interpreter at `0x1403B5F40`. It does not admit TrueType glyph rendering.

`TrueTypeInterpreterState` owns storage and already-scaled CVT words across preparation and glyph calls. Its caller supplies the actual maxp storage count, scaled CVT and size/driver metrics. The component checks its owner bounds; it does not infer a font size, scale, raster mode or point owner. Graphics defaults match the original 68-byte state copied from `0x14060C1E0`; super-round working fields match `0x1403BC402`.

The new execution entry shares the accepted stack/control engine and immutable FDEF owner. Existing stack/control entry points retain their opcode gates. Zone selection preserves scalar zone identities; no point operation is admitted. Preparation and glyph byte spans need only remain alive for each execution; state words and returned operands own their storage.

At `0x1403B71B2`–`0x1403B72A0`, storage uses an unsigned index against a 16-bit count, and CVT uses a 32-bit count. Invalid non-pedantic writes are ignored and reads return zero; pedantic execution reports `0x86`. Fixed-group underflow retains the accepted native zero-group rule. `WCVTF` and `SSW` execute the signed fixed-point kernel at `0x14039CDA0`: its logical shift extracts one sign bit before subtraction, so negative half ties round away from zero. Return values retain their low 32 bits.

Rounding dispatch uses the original mode numbers and the helpers at `0x1403B41C0`–`0x1403B43A1`. Signed word overflow, compensation, half-grid clamps, super-round period/phase/threshold truncation, and the distinct bit-mask versus signed-remainder kernels remain explicit. `SDB` is opcode `0x5E` and `SDS` is `0x5F`; `0x5D` remains a gated point instruction. `SDS` rejects values outside 0–6; `SLOOP` accepts zero and rejects negatives. `INSTCTRL` keeps the original three selectors and version-40 compatibility update. `GETINFO` preserves the original capability masks; two observed driver booleans retain their native field-offset names because broader raster-policy provenance is separate.

Unequal X/Y ppem CVT/MPPEM projection remains gated: the original calls its cached vector-length ratio path at `0x1403B1EB0`. Dynamic definitions, non-axis vector construction, point movement/interpolation, delta application, hint-policy integration and raster preparation remain unrecovered here. The added CVT owner cap is one MiB of decoded bytes; storage remains bounded by its native 16-bit count. Invalid caller-supplied super-round periods are rejected before division. These are first-party safety boundaries, not measured original allocation limits.
