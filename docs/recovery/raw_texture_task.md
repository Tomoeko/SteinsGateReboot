# RawTex task ownership

Target `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Original `MRawTex` constructor `0x1404f8ef0` calls fixed-size view `0x1404c05a0` and process `0x1404bfb10`; its unchanged vtable is at `0x140651ef8`.

`RawTextureTask` owns a genuine exclusive CPU-shadow texture and separate embedded serial/parallel process groups. The original four color-mode C strings select DXGI 87 for `8888`/`8888_BGRA`, 88 for `8888_BGRX`, and 28 for `8888_RGBA`. Each texture uses kind 2, one mip and one sample, with filters zero/zero. Positive logical float dimensions truncate into texture dimensions while the draw packet retains the original logical extent. The task starts active with drawing paused, coordinate zero, stored RGB `ffffff00`, opacity 255 and blend zero. The script wrapper separately enables drawing after creation.

Coordinate writes use `0x1404f9720`; color conversion uses `0x1404f96b0`; full-width opacity writes use `0x140390380`. Drawing consumes the opacity low byte through the separately verified [color](raw_texture_color.md) and [four-vertex packet](raw_texture_packet.md) helpers. The caller still owns camera/clip traversal, status/pause selection, pipeline preparation, texture binding and physical submission. This owner does not substitute ordinary colored vertices for the original XY/UV interface.

Generic update `0x1404c0500` skips every nonzero task status. The default unthreaded process path `0x1404c0380` updates an active serial group before an active parallel group, independent of drawing pause. Embedded groups retain active status when empty. Original RawTex's idle callback is the inert `0x140030f20`. Group retirement follows actual task semantics rather than clearing completed serial ownership implicitly.

Synchronous image/RGB restoration uses the real texture shadow/map/pitch/dirty/unlock owner with [verified row conversion](raw_texture_restore.md). The image frontend checks truncated integer dimensions first; helper `0x14005d1f0` then requires exact float equality. Fractional logical extents can therefore pass the integer check and intentionally leave image pixels, dirty and lock state untouched. RGB uses the integer extent and snapshots the supplied bytes before mapping. Image copies preserve BGRA bytes for every requested physical color mode; no extra channel or alpha correction is invented. Upload is deferred until texture binding.

Destructor `0x1404f90c0` releases its texture before clearing the embedded parallel group and then the serial group. The C++ owner follows that order, completes valid cleanup after callback failures, and reports the first failure at explicit Close. Destructor cleanup remains nonthrowing. Closed owners reject subsequent operations. Reentrant update or Close during its own active update or a directly borrowed group callback is an explicit first-party safety error before ownership changes; task groups are borrowed for preparation and registration, and ordinary dispatch belongs to this owner.

The mutable factory/release, empty group retirement and bounded heap are declared observer boundaries. The C++ comparison observes actual texture and registered group-release callbacks; nested owner/backend behavior has its separate [mutable texture evidence](mutable_texture_owner.md). This is composed CPU ownership evidence, not a native GPU capture or full initialized script engine.

A further 1,000 original image-helper cases execute 53,096 instructions, with exact whole prepared byte arrays and dirty/lock states across integer and fractional dimensions. Trace SHA-256 `1d96ac9dc0d5ebf7375fb98abd13696fbc15fd21ee7b581a33797ceeb732d334`; all authored cases match. Seven independent ASan/UBSan fixture groups cover actual texture/channel ownership, no premature upload, fractional copy behavior, packet extent/color, serial-before-parallel update, nonzero status, release despite failure, no double retirement, borrowed-callback retirement rejection and bounded invalid-input rejection.

Texture extents are restricted to finite positive values from 1 through 16,384 and the separately checked 64 MiB shadow bound. Unknown format strings are rejected rather than reproducing the native uninitialized pointer-derived format. These safety checks do not claim native behavior for invalid dimensions, allocation failures or unsafe reentry.
