# macOS performance counter

Original `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`, samples Windows QueryPerformanceCounter in `0x1405361c0` and projects it through the separately verified integer-frequency millisecond conversion. Worker helper `0x140546ce0` instead retains the raw counter's low DWORD for task cost. These units remain distinct.

`HostPerformanceCounter` reads the actual macOS timebase once and samples `mach_continuous_time`. The [Apple API header](https://github.com/apple-oss-distributions/xnu/blob/main/osfmk/mach/mach_time.h) specifies that this clock advances during sleep. [Microsoft's QPC documentation](https://learn.microsoft.com/en-us/windows/win32/sysinfo/acquiring-high-resolution-time-stamps) specifies the same sleep-inclusive interval domain. This is a documented port choice, not a measured cross-platform clock equality claim.

The host frequency is exactly `1,000,000,000 * denominator / numerator`; zero, unavailable or nonintegral frequencies reject rather than silently changing the recovered projection. Raw sampling retains the signed input range required by the portable conversion. The public header contains only standard integer types. All Mach API usage remains in the macOS boundary; there is no mutable global clock or portable fallback.

The actual Apple Silicon host reports 24,000,000 ticks per second. A pinned four-unit ASan/UBSan check compares the frequency against the independently queried OS timebase, contains a millisecond sample between raw OS samples and verifies 8,192 monotonic samples across two real threads. It then feeds the actual millisecond sample into the portable FrameClock. The test owns and joins both threads, including partial-construction failure. Apple Clang16's unavailable `std::jthread` was a retained test-only compile failure before that explicit ownership correction. The generated executable is hashed and retired.

This check performs no sleep/wake transition, event pumping, VSync scheduling, game process, visible window or speaker output. Actual native timing, host resume behavior in the game, worker scheduling/cost correspondence, shared-seed entropy and full application integration remain open. When a distributable application bundle is authored, its Apple required-reason API metadata must include the actual elapsed-time use; no bundle is produced by this component.
