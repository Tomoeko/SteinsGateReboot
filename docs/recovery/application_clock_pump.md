While suspended, the pump first checks accepted close, quit and the existing wait-break flag. Otherwise it invokes the current auxiliary receiver with `true`, waits sixteen milliseconds, flushes real event requests and dispatches/paces again. Resumption samples the clock and invokes the auxiliary receiver with `false`. Quit marks the exact current root status `Retire`; accepted close clears close then requests quit. The final flush follows those decisions. Requests made by an auxiliary callback therefore affect the subsequent flush and invocation, preserving native delayed close-to-quit ordering.
