# Fixed text glyph atlas ownership

Target: `Files/STEINS.GATE.REBOOT/sgre_steam.exe`, SHA-256 `75a83a0e2a7e22055417ae0474b47be98418c4e42c695c548b558705c404b9d8`. Addresses are executable virtual addresses; Binary Ninja used `candidate:view:2:UEU`, read-only.

`TextGlyphAtlasOwner` owns the original text context's lazy fixed 1024×1024 CPU-shadow BGRA8 texture. Private font interfaces borrow its regions and retire before this owner. Construction allocates no texture. Empty glyphs produce no texture or cache region. Default CFF path/cells are prepared before mapping; the actual CPU storage is filled directly at the allocated interior address with atlas-wide pitch. Preparation performs no GPU bind or readback.

## Native ownership and state

Base text constructor `0x1400356c0` initializes extent `+0x418` to 1024, clears pen X/Y and row height at `+0x41c..+0x424`, and leaves texture `+0x428` null. `0x140086bb0` lazily creates one 120-byte texture wrapper through `0x1404f8410`/`0x1404f87a0`: storage kind 2, format 87, width/height 1024, one mip/sample, shader-resource binding, CPU shadow 4,194,304 bytes, pitch 4096. Initial filtering is set to zero, then the text context's duplicated filtering words are applied. `0x140036cb0` changes that context byte and propagates filtering when the texture exists. The original owner's existing-sampler invalidation behavior is preserved by [mutable_texture_owner.md](mutable_texture_owner.md); changing filtering alone does not replace an already-created sampler.

Allocator `0x1400369c0` creates the texture before the row gate, preserves horizontal row wrapping even when height fails, and maps only after the strict height check. It clears the padded rectangle, advances packing, and returns the atlas interior. `0x140087020` unlocks CPU shadow storage without an OS/GPU unmap; dirty state remains until explicit `Bind` invokes the accepted upload/sampler/resource-bind path. Atlas retirement `0x140086fb0` releases this exclusive texture and clears the pointer. There is no recovered automatic page growth in this path.

`ScriptTextFontInfo` connects each actual vector interface's size/border/glyph cache to its one borrowed text atlas. Cache misses update the actual borrowed VectorFont size, prepare the default CFF glyph, and cache the six placement words. Empty or full-atlas results are zero-valued entries and are not retried. Separate interfaces have separate caches but may share the owning text context's atlas. Draw preparation only returns existing cached rectangles; it never rasterizes, binds, uploads, or submits. Nonzero border requests remain explicit unsupported stroke errors.

## Validation and limits

A dormant CPU replay executes unchanged constructor/filter/lazy texture/row allocator/map/pitch/unlock/bind/retirement instructions for 50 original owners and 650 steps. Authored state, allocation, descriptor flags, filtering and cumulative resource events match all 26,650 projected words. The full compact native trace retains event order; SHA-256 is `672970b89ef5679b38dbc103aceff95486ae07f091a59f5dbce2c7ff25d8dd3e`. Caller allocation, base-view/TextRender initialization, prepared 4 MiB shadow storage, bounded memset and D3D services are explicit observers. This replay has no OS/GPU callback, original-game launch, glyph-raster pixel claim, or observation of native uninitialized shadow bytes.

The immutable raster/row helper refactor also preserves all earlier 9,000 allocator words/1,000 whole-buffer hashes and the retained original 30-CFF-glyph 360-word/30-atlas-hash regression. Actual FontInfo constructor/lifetime and interface/core size regressions still match 9,000 and 70,000 native words. Independent strict-warning ASan/UBSan tests cover lazy construction, exact rectangle bytes, empty glyphs, fixed height failure before mapping, shared atlas/separate caches, failed-region retention, explicit upload phases, filtering quirks, retirement and reentrant callback rejection. The portable owner initializes its shadow safely to zero; only padded regions and supported raster writes carry native pixel evidence.

The supported scope is default unstroked CFF glyph preparation into the genuine fixed text atlas and cached rectangle generation. Stroke pixels, TrueType outlines/hinting, contextual shaping/fallback, full TextRender selection/layout/application, GPU shader coupling and final text frames remain open. Glyph preparation allocates bounded temporary CPU geometry and belongs outside ordinary frames. The backend and atlas context outlive borrowed interfaces and every returned resource view.
